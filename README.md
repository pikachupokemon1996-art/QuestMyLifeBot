# Квестификатор ⚔️

Telegram-бот с интеграцией Gemini API.

Функции:
- принимает задачи пользователя;
- отправляет запрос в ИИ;
- получает игровой квест;
- возвращает ответ в Telegram без Markdown.

Запуск:

1. Установить зависимости:
pip install -r requirements.txt

2. Создать файл .env

3. Запустить:
python bot.py
