# Квестификатор ⚔️

Telegram-бот с Gemini API, который превращает обычные дела в RPG-квесты.

## Vercel
После деплоя добавьте переменные TELEGRAM_BOT_TOKEN и GEMINI_API_KEY.
Затем откройте https://ВАШ-ПРОЕКТ.vercel.app/api/setup один раз.
Проверка сервиса: https://ВАШ-ПРОЕКТ.vercel.app/api

Ответы отправляются обычным текстом без Markdown.
Общий XP между запросами в бесплатной serverless-версии не хранится.
